--controls--
exit window = ESCAPE
restart from a checkpoint = R

move left = the left arrow key
move right = the right arrow key
fast fall = the down arrow key

transform into the jump player = Z
transform into the double jump player = X
transform into the dash player = X
transform into the slide player = V

the special of each player = SPACE

--special instruction--
to use the double jump you must be in the air.
the slide will deactivate when you'r x velocity becomes 0.
dash and slide will be faster if you move in the corresponding direction.
